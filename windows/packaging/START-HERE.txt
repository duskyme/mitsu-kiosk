CP-9550 Native — unofficial TEST build
======================================

THIS IS NOT a Microsoft WHQL or Mitsubishi Electric product.
Drivers are test-signed (WDKTestCert). Use only on lab / owned machines.

Quick path (Windows 11 x64)
---------------------------
1) Connect the CP-9550DW-S (USB VID 06D3 / PID 03A5).
2) Open an already-elevated Admin PowerShell (do not rely on UAC prompts from scripts):
     cd "C:\Program Files\CP9550 Native"
     .\Install-Drivers.ps1
   This runs WinUSB -Sign and V4 queue -Sign (DriverVer 0.4.1+).
3) Non-Admin:
     .\Start-Tray.ps1
   Tray icon near the clock; auto-starts SpoolBridge when USB appears.
4) Print from any app to queue: "Mitsubishi CP-9550DW-S (V4)".

Signing / testsigning
---------------------
Preferred: WDKTestCert in CurrentUser\My AND imported to LocalMachine\Root
  + TrustedPublisher → Driver Signature Enforcement accepts packages without
  bcdedit testsigning.
Fallback: bcdedit /set testsigning on (+ reboot) if the cert is not machine-trusted.
Secure Boot machines still need a trusted test cert or testsigning.

Tray / bridge notes
-------------------
- SpoolBridge listens on 127.0.0.1:9100 (RAW) and calls WinUSB SendSpool.
- Never leave a --dry-run bridge running for real prints: Windows reports SUCCESS
  while the printer stays idle. Use Start-Tray.ps1 without -DryRun.
- If tray OpenUsbDevice polling killed mid-job SendSpool, update to the build
  that gates USB opens while a job is in flight (PR #6 / 0.4.1 stack).

Troubleshooting
---------------
- GUID FormatException / WinUSB bind fails:
  Re-run Admin Install-Drivers.ps1 (or winusb\install.ps1 -Sign). Old packages
  with non-hex DeviceInterface GUID (c9550dws…) must be purged; expected GUID is
  {D3C9550A-06D3-4A55-9D77-C9550D050001}.
- PrintService 372 / filter never initializes:
  Pipeline XML comments must not contain "--". Use the shipped pipeline.
- XPS_E_INVALID_MARKUP (0x8052000C):
  Needs filter CreatePageFromStream1 + XpsFormat XPS,OpenXPS (0.3.11+).
- Job OK in Windows, printer idle:
  Kill dry-run SpoolBridge; restart tray without -DryRun.
- pnputil exit 259:
  Package already present — install-printer.ps1 treats it as OK; use -ForceReplace
  to refresh.

Architecture (hybrid)
---------------------
App Print dialog → V4 GPD + XPS IHV filter → planar RGB spool
  → Standard TCP/IP Port 127.0.0.1:9100
  → Cp9550SpoolBridge → WinUSB SendSpool → CP-9550DW-S
